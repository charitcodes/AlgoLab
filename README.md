# 🚀 AlgoLab Studio

### Interactive Analysis of Algorithms Laboratory

**AlgoLab Studio** is an interactive web application designed to visualize and understand important algorithms from the Analysis of Algorithms (AOA) syllabus. It provides step-by-step visualizations to make complex algorithmic concepts easier to learn.

🌐 **Live Demo:** https://algo-lab-phi.vercel.app/

💻 **GitHub Repository:** https://github.com/charitcodes/AlgoLab

---

## ✨ Features

- 🎨 Modern, responsive dashboard with a dark-themed interface
- 📊 Interactive algorithm visualizations
- ⚡ Sorting algorithm demonstrations
- 🌐 Graph traversal and shortest-path visualizations
- 🧮 Dynamic programming demonstrations
- ♟️ N-Queens problem visualization
- 📚 Algorithm-focused learning interface

## 💻 Run Locally

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/charitcodes/AlgoLab.git
   ```

2. Open the project directory:

   ```bash
   cd AlgoLab
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```
